# Social Post

Built Sentinel Graph for the TigerGraph × Hacker House Goa fraud challenge: a bounded LangGraph investigator over 590K transactions, using TigerGraph MCP for evidence retrieval and persistent case memory.

The fun constraint was making the system genuinely accountable. Risk scores are treated as clues, every query is time-safe, approval routes are code-enforced, evidence requests can change the recommendation, and the LLM is allowed to polish prose—but never the verdict.

The submission includes all 20 validated investigations, SAR and next-action logic, graph write-back, and a Streamlit analyst console. Fraud detection gives you a score; fraud investigation should give you a defensible story and an auditable decision.
